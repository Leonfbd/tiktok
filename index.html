🔑 Klucz API i model

Klucz jest używany tylko w Twojej przeglądarce do bezpośredniego wywołania API wybranego dostawcy. Aplikacja nie ma backendu i nie wysyła danych nigdzie indziej. Uwaga: dla plików otwartych przez file:// niektóre przeglądarki blokują żądania – wtedy uruchom prosty serwer lokalny (patrz README) lub użyj silnika lokalnego.

🧠 Silnik lokalny (offline)

Silnik lokalny buduje pakiet z banków fraz, strategii i struktur ujęć – bez internetu i bez klucza. Pełne banki treści: polski i angielski. Dla pozostałych języków offline generuje bazę po angielsku z lokalnymi CTA i hookami (pełna lokalizacja copy – tryb API).

💾 Pamięć lokalna

Przeglądarki dają zwykle ok. 5 MB na localStorage. Historia jest automatycznie przycinana, gdy przekroczy bezpieczny rozmiar.

⌨ Skróty i szybkie akcje

Ctrl + EnterGeneruj pakiet
Ctrl + SZapisz projekt do historii
Ctrl + KOtwórz okno klucza API
Ctrl + Shift + LSzybki pakiet lokalny

Auto-save: brief i wyniki zapisują się automatycznie w localStorage po każdej zmianie – możesz zamknąć kartę i wrócić.

Klucz API

Klucz zostaje w localStorage tej przeglądarki. Możesz go w każdej chwili zmienić lub usunąć w Ustawieniach.

Bez klucza aplikacja nadal działa – generuje pakiet silnikiem lokalnym offline.
